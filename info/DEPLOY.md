# Передача и размещение «Смена»

## Что передаю

- Исходники React в `src/`, готовый сайт в `public/`, файлы сборки и проверки.
- `start.cmd` для Windows и `preview.mjs` для локального запуска на Node.js 22 или новее.
- Инструкцию по размещению и переносу данных.

## Размещение в аккаунте заказчика

1. Скачайте [репозиторий проекта](https://github.com/Denis-Zag/staff-planner) или клонируйте его. Распакуйте архив, если скачивали его с GitHub.
2. Войдите в свой аккаунт [Netlify](https://app.netlify.com/). Откройте [Netlify Drop](https://app.netlify.com/drop).
3. Перетащите папку `public/` из репозитория в область загрузки. В корне этой папки должны быть `index.html`, `app.js` и `style.css`.
4. После публикации откройте выданный адрес `*.netlify.app` в окне без входа в аккаунт. Добавьте вымышленную запись, обновите страницу и проверьте её сохранение.

Для загрузки готовой папки Node.js и отдельный сервер не нужны. [Документация Netlify Drop](https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/).

## Как обновлять

После изменений в исходниках выполните `npm ci` и `npm run build`. Загрузите обновлённую папку `public/` в разделе Deploys существующего проекта, чтобы сохранить его адрес.

## Данные и перенос

Записи хранятся в браузере для конкретного адреса приложения. Перед сменой адреса или браузера скачайте JSON-копию и импортируйте её после перехода. Общей базы данных и синхронизации между пользователями в этой версии нет. Храните резервные копии отдельно от публичного репозитория.
