# Передача и развёртывание

Файлы: src (React-исходники), dist (готовый сайт), package.json и package-lock.json (сборка), preview.mjs и start.cmd (локальный запуск), tests (проверка), info (ТЗ, источник и промпты), evidence (скриншоты).

Сервер: статический учебный стенд Sites, без общей БД и учётных записей. Данные остаются в браузере посетителя.

Инструкция по деплою: выполните npm ci, npm run build и загрузите каталог dist на статический хостинг. Для Sites сохраните связанный project_id из .openai/hosting.json. Для Netlify: Build command — npm run build; Publish directory — dist. Netlify здесь не использовался. Railway не использовался. Тариф и лимиты любого стороннего сервиса проверяйте перед самостоятельной публикацией.

Перед сменой адреса сайта скачайте JSON-копию. Данные не переносятся между адресами автоматически. Проверяйте открытие сайта без входа в аккаунт и работу формы после размещения.
